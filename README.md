# Wassertein-GAIN-Attention

The data for this analysis was sourced from the Food and Agriculture Organization (FAO) website, focusing on three essential crops: rice, soya, and corn. Collected variables cover 16 indicators: Item (crop), Area (country), Year (1961 to 2023), AreaHarvested, Production, Yield, Price, ExportQuantity, ExportValue, ImportQuantity, ImportValue, RuralPopulation, UrbanPopulation, TotalPopulation, and GrossNationalIncome (GNI). The data was organized in a panel format. This structure enables cross-sectional (country comparisons) and time series (yearly trends). This dataset summary provides an aggregated view of key metrics for each crop—corn, rice, and soya—by averaging values across all relevant columns. Table \ref{tab:data} shows that the Total Row indicates that 693 entries were collected for each crop. The Count metric represents the average number of non-null values across all columns. The Mean value reflects an aggregate average across columns for each crop. The Std value is the average standard deviation across columns, giving each crop an overall measure of variability.
